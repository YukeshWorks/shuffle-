# RingShift — Android ringer scheduler

RingShift switches Android between Ring, Vibrate, and Silent using Android's native AudioManager API.

## Latest release

- Version: 1.1.0
- Package: `com.yukeshworks.ringshift`
- App source: `ringshift/`
- New in 1.1.0: From → Until daily ranges, separate return mode, AM/PM time picker, safer system-bar insets, vector app icon, and subtle animations.

## Android access required

- Notification Policy Access — to change the actual ringer mode.
- Alarms & reminders / exact alarm access — to run scheduled changes on time.

Schedules are stored locally on the device. No login, server, tracking or ads.
